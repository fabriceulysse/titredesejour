🇫🇷 Moniteur de RDV — Titre de Séjour

Configurez votre moniteur gratuit en 5 minutes. Il vérifie les créneaux toutes les 5 minutes et vous envoie un email dès qu'un rendez-vous est disponible.

🔴 "Nous ne sommes pas en mesure de traiter votre demande" — que signifie cette erreur ? Ce message sur le site ANEF ne signifie PAS qu'il y a un problème avec votre dossier. Il signifie simplement qu'aucun créneau n'est disponible en ce moment. Votre dossier est en ordre. Les créneaux s'ouvrent souvent à l'intérieur de la fenêtre de 2 mois avant l'expiration de votre titre.
⏰ Quand activer le moniteur ? Les créneaux ne sont généralement accessibles que dans les 2 mois avant l'expiration de votre titre de séjour. Activez ce moniteur dès que vous entrez dans cette fenêtre.

3

Mettre en place le moniteur (tout dans le navigateur)

  • A
    Forkez le dépôt GitHub Cliquez sur le bouton ci-dessous. GitHub crée une copie privée sous votre compte — c'est là que tournera le moniteur.
    ⑃ Forker le dépôt sur GitHub
  • B
    Remplacez le fichier config.json Dans votre fork, cliquez sur config.json, puis sur l'icône crayon ✏️. Effacez tout le contenu et collez le JSON que vous avez copié à l'étape 2. Cliquez sur Commit changes.
  • C
    Créez un mot de passe d'application Gmail Votre compte Gmail normal ne fonctionne pas pour l'envoi automatique — vous devez créer un App Password :
    1. Activez la validation en 2 étapes : myaccount.google.com/security
    2. Générez un mot de passe d'app : myaccount.google.com/apppasswords
    3. Nom : "RDV Monitor" → cliquez Créer
    4. Copiez le mot de passe à 16 caractères (il ne s'affiche qu'une fois)
  • D
    Ajoutez vos secrets GitHub Dans votre fork : Settings → Secrets and variables → Actions → New repository secret
    Nom du secretValeur
    SMTP_USER votre adresse Gmail (ex: jean@gmail.com)
    SMTP_PASSWORD le mot de passe à 16 caractères de l'étape C
  • E
    Activez GitHub Actions Dans votre fork, cliquez sur l'onglet Actions. Si un message vous demande d'activer les workflows, acceptez. Cliquez ensuite sur Check Appointment Availability → Run workflow → Run workflow pour lancer un premier test manuel.
  • F
    Vérifiez que ça fonctionne Actualisez la page Actions après quelques secondes. Cliquez sur le workflow run. Dans les logs, vous devriez voir :
    No slots available. Will check again at the next scheduled run.
    C'est normal si aucun créneau n'est disponible. Le moniteur continuera à vérifier toutes les 5 minutes automatiquement. Quand un créneau s'ouvre, vous recevrez un email.
⚠️ Ce moniteur vous alerte uniquement — il ne prend pas rendez-vous à votre place. Dès que vous recevez l'email, connectez-vous immédiatement sur le site officiel pour réserver. Les créneaux disparaissent souvent en moins d'une minute.
